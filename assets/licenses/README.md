# Asset provenance

- **Inter variable font:** distributed by `@fontsource-variable/inter`; copyright The Inter Project Authors; SIL Open Font License 1.1. The canonical license is in `Inter-OFL.txt` and is copied into every production build.
- **Motion graphics and renderer:** original code-authored work created for Motion Plug. No Apple artwork, advertising footage, or extracted assets are included.
- **Sound effects:** edited excerpts from the user-supplied Epidemic Sound MP3 recordings in `drive-download-20260913T121912Z-1-001`. Source filenames, excerpt positions, and processing are recorded in `assets/sfx/sources.json`. These recordings are third-party assets, not original Motion Plug synthesis.
- **Plugin and panel icons:** the user-supplied `MotionPlug_Logo.png`, copied without visual changes; `scripts/generate-icons.mjs` creates the required icon sizes.
- **Custom fonts:** imported by the user and stored locally. They are not bundled in the distributable extension.
