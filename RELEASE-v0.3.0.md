# Motion Plug v0.3.0

Initial user-ready release of Motion Plug for Adobe Premiere Pro.

- Includes 30 original, customizable motion-graphics presets across 15 animation families.
- Adds matching offline sound effects and timeline-aware transparent rendering.
- Ships per-user macOS and Windows installers plus an integrity-checked in-panel updater.
- Keeps favorites, recent items, saved variations, preferences, and imported fonts on the user's machine.
- Requires no account, sign-in, subscription, license key, cloud renderer, or API key.
